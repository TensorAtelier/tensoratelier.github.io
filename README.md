# tensoratelier.com

Static site for Tensor Atelier: what it is, the project catalog, and the Patreon link.
Plain HTML + CSS, no build step. Preview with `python3 -m http.server` and open http://localhost:8000.

- Add a project: copy an `<article class="card">` in `index.html`, put a 1200px-wide screenshot in `img/`.
- Social links: add them to the footer `<nav>` once the accounts exist.
- `CNAME` is for GitHub Pages (custom domain `tensoratelier.com`).
