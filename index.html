About

Made with AI

An atelier is a workshop where things are made by hand. This one is one person working with AI coding tools, which makes it possible to build far more, and to give it away.

For people

Every project is small, free and open source, and should be usable within a minute, with no setup where possible. Nothing is locked behind a paywall.

Backing it

If you'd like more of this, back it on Patreon. Or just use the things, star the repos, and file issues on GitHub when something breaks.

Like what's being made?

Patreon support pays for the time and the machines that build the next project. Backers get early looks, the story of how each one was built, and a say in what comes next.
