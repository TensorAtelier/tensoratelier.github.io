About

What this is

An atelier is a workshop where things get made by hand. This one is run by one person working with AI coding tools: pick an idea, build it properly, and put it out in the open with the source.

Why it's free

It's an experiment in whether people will back work like this. The projects stay open source and free to use; nothing is locked behind the paywall.

How to help

Back it on Patreon if you'd like more of it. Or just use the things, star the repos, and file issues on GitHub when something breaks.

Like what's being made?

Patreon support pays for the time and the machines that build the next project.
